# OG-Suite

goal of this app is to have a suite of tools that can replace anything i use big tech solutions and instead have them on my home lab.

## Current main feantures

- Concurrent user Rich text editor for notes and document editng.

<img width="1880" height="959" alt="image" src="https://github.com/user-attachments/assets/7194f758-3b79-4036-9a95-e39cdff9737e" />

- Audio recording and transcription so you can have a place to record and store audio on a backend server.

<img width="1894" height="950" alt="image" src="https://github.com/user-attachments/assets/0f619fa7-d1df-4962-8856-ceba7256f73e" />

- Admin panel to see database data and adjust user access to these tools. Default user: Admin:password
- Appearance menu to put the power in the users hands to make this look how they want it.

Future Tools:
- Coms menu to have threads and private messages beteen users and also be able to host audio/video and screen sharing calls
